# 🎓 EduPro Learning Management System (LMS) - Desktop GUI Application

This project is a complete, standalone Java GUI desktop application for presenting a full Learning Management System platform to teachers and evaluators.

## 🚀 Quick Start (1 Click)
- **Double-click [`run_gui.bat`](run_gui.bat)** or navigate into [`java gui/`](java%20gui/) and double-click [`run.bat`](java%20gui/run.bat).
- Alternatively, run the executable JAR:
  ```powershell
  java -jar "java gui\EduPro-LMS-Desktop.jar"
  ```
